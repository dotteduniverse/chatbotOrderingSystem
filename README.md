# 🍵 AI-Powered Chatbot Ordering System

An intelligent chatbot for ordering tea, coffee, and snacks, built with modern AI technologies including LangChain, RAG (Retrieval-Augmented Generation), and vector databases. This project serves as both a functional ordering system and a learning platform for exploring LLM-powered applications.

## ✨ Features

- **Interactive Chat Interface**: User-friendly chatbot UI built with Streamlit
- **Menu Intelligence**: RAG-powered system that understands menu items, prices, and customizations
- **Conversation Memory**: Remembers user context and order history within a session
- **Order Processing**: Extracts and structures orders from natural language
- **Local or Cloud LLM**: Choose between running models locally with Ollama or using cloud APIs

## 🎯 Learning Objectives

This project is designed to teach you:
- Building LLM-powered applications with LangChain
- Implementing RAG with vector databases (ChromaDB)
- Creating interactive UIs with Streamlit
- Integrating conversational memory in AI applications
- Structuring API backends with FastAPI
- Containerizing AI applications with Docker

## 🛠️ Technology Stack

| Component | Technology | Purpose |
|-----------|------------|---------|
| **Language** | Python 3.10+ | Core development language |
| **Framework** | LangChain | LLM orchestration and RAG pipelines |
| **LLM Options** | Ollama (local) / Groq API (cloud) | Natural language understanding |
| **Vector DB** | ChromaDB | Menu embeddings for semantic search |
| **UI** | Streamlit | Interactive chat interface |
| **Backend API** | FastAPI | RESTful API endpoints |
| **Embeddings** | sentence-transformers | Menu text vectorization |
| **Container** | Docker | Application containerization |

## 📋 Prerequisites
